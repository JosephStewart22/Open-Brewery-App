# 🍺 The Brew List

A modern React brewery directory application that allows users to browse, search, filter, add, and remove breweries.

The project uses React for the frontend and JSON Server as a lightweight local REST API for brewery data.

---

## ✨ Features

- 🔎 Search breweries by name
- 🏷️ Filter breweries by type
- 🐕 Filter for pet-friendly breweries
- ➕ Add new breweries
- 🗑️ Remove breweries
- 🌙 Dark and light mode
- 🧭 Client-side routing
- 📱 Responsive design
- 🎨 Custom modern UI
- ⚡ Frontend and backend launch with one command

### Available Brewery Filters

- All Breweries
- Micro
- Large
- Brewpub
- Pet Friendly

Search and filtering can be used together.
